# 영웅이랑 매일 v2.0.1

공개 앱: https://youngwoong-haru.netlify.app/

카카오톡에는 상위 폴더의 `영웅이랑-매일.html`을 보내거나 링크를 보내세요. HTML은 최신 앱을 여는 작은 안내 파일입니다.

## 처음 설치
갤럭시 Chrome에서 주소를 연 뒤 메뉴 → 홈 화면에 추가/앱 설치. 앱 설정의 업데이트·오프라인에서 저장 완료를 확인하세요. YouTube 영상과 새 자료 확인에는 인터넷이 필요합니다.

## 포함 기능
- 공식 영상·숏츠 21개, 기본 공식 사진·앨범 카드 12개, 팬 놀이 8종
- 걸음 목표 1천·3천·5천·1만보 및 직접 설정. 삼성헬스 값을 수동 입력하며 자동 만보계가 아닙니다.
- 산책 타이머, 오프라인 3분 의자 루틴, 공식 기관 운동 영상 4개
- 식사·물·휴식·가족 안부 및 날짜별 할 일
- 공공기관·병원 자료 기반 건강 카드 6개와 식품 예시. 일반 정보이며 의료진 지시가 우선입니다.
- 시간대별 글 인사. 사용자 요청으로 음성 합성·AI 음성 파일·화면 읽기 기능은 제외했습니다.
- 팬메이드 규칙형 대화이며 LLM·실제 임영웅과의 채팅이 아닙니다.

## 저장·업데이트
기록은 브라우저 localStorage에 저장되며 서버로 전송하지 않습니다. 개인정보 입력은 선택이고 다른 기기로 자동 동기화되지 않습니다. 브라우저 데이터 삭제 전 백업하세요. 서비스워커는 앱 껍질·기본 사진·건강·게임·글 인사를 저장합니다. 새 사진은 열어 본 이미지에 한해 저장될 수 있습니다.

앱은 연결 시 media.json을 확인하고, GitHub Actions의 매일 자동 작업이 공식 공개 사진·영상 출처를 점검합니다. 자료만 바뀔 때는 Netlify 재배포 없이 적용됩니다. 공식 자료 확인 시각과 앱 동기화 시각을 구분합니다. 회원 전용 공지는 수집하지 않습니다. 무료 호스팅 한도를 초과하면 배포·접속이 중단될 수 있으며 유료 자동 충전은 사용하지 않습니다.

앱을 닫아 둔 상태의 정시 음성 인사, 백그라운드 걸음 측정, 알림은 제공하지 않습니다.

## 라이선스
음악·가사·운동 영상 파일은 포함하지 않습니다. 공식 플레이어/링크로 연결합니다. 원본 사진 권리는 원권리자에게 있습니다. 음성 모델·복제 목소리·AI 인사 음성 파일은 배포물에 포함하지 않습니다.
