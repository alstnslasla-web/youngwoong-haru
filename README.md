# 영웅이랑 매일 v2.1.0

공개 앱: https://youngwoong-haru.netlify.app/

가족을 위한 비공식 팬메이드 앱입니다. 임영웅 또는 소속사의 공식 서비스가 아니며, 실제 가수와 대화하거나 의료 조언을 받는 서비스가 아닙니다.

## 처음 설치

갤럭시 Chrome에서 주소를 열고 메뉴 → 홈 화면에 추가/앱 설치를 선택하세요. 카카오톡 안에서는 ‘다른 브라우저로 열기’로 Chrome을 이용하세요. ‘업데이트 · 오프라인’에서 기본 자료 저장 완료를 확인하세요. 오래 열린 앱은 새로고침 한 번이 필요할 수 있습니다.

## 포함 기능

- 큰 글씨·큰 버튼, 공식 영상·사진·앨범, 노래 연습, 팬 놀이와 퀴즈
- 걸음 목표 1천·3천·5천·1만 보 및 직접 설정. 삼성헬스의 누적값을 수동 입력하며 자동 만보계가 아닙니다.
- 산책 타이머, 오프라인 3분 의자 루틴, 공식 기관 운동 영상 4개
- 식사·물·휴식·가족 안부, 날짜별 할 일과 개인 기록
- 공공기관·병원 자료를 근거로 한 건강 카드 6개. 일반 정보이며 개인별 의료진 지시가 우선입니다.
- 제공된 AI 샘플의 아침 인사와 이를 참고해 만든 낮·저녁 인사
- 미리 준비된 공개 안내 읽기와 정지. 메뉴·건강·걷기·놀이·공식 자료의 안내를 대상으로 하며, 준비되지 않은 문구는 읽지 않고 알립니다.

## AI 음성 방식과 한계

앱은 즉석에서 음성을 합성하지 않습니다. 공개된 문구로 미리 만든 음성 파일만 내려받습니다. 브라우저/기기의 기본 목소리나 다른 일반 음성으로 대체하지 않습니다.

‘화면 안내 듣기’는 검토한 공개 안내를 읽는 기능이며, 화면 전체를 임의로 훑어 읽는 기능이 아닙니다. 이름·대화·할 일·일기·개인 일정·건강 기록·직접 넣은 가사·연습 메모·녹음·백업은 음성 합성에 사용하거나 외부로 보내지 않습니다. 인사는 정해진 문구여서 화면의 이름이 들어간 글 인사와 다를 수 있습니다.

안내에 필요한 모든 음성 조각이 준비되고 내려받아져야 재생합니다. 일부 건강 안내만 잘라 들려주지 않습니다. 듣기·재생 버튼을 직접 눌러야 하며, 화면 이동·창 닫기·앱 숨김 시 읽기를 멈춥니다. 기본 재생 속도는 0.9배입니다.

현재 공개 문구 목록은 166개이며, 낮 인사를 포함한 생성 계획은 187개 고유 음성 조각입니다. 실제 완료 범위는 공개 voice-index.json의 complete 항목으로 확인합니다. 문구가 바뀌거나 새 공식 자료가 추가되면 해당 음성은 다시 준비해야 합니다. 모든 미래 콘텐츠의 자동 음성 생성을 약속하지 않습니다.

첫 다운로드에는 인터넷이 필요합니다. 기본 인사는 앱 기본 저장에 포함하고, 공개 안내는 최근 사용한 최대 50조각 또는 30MiB까지 저장합니다. 기기에 남아 있는 음성만 오프라인에서 다시 재생할 수 있습니다. 저장 공간 정리·브라우저 정책·오래된 캐시 정리로 파일이 없어질 수 있습니다. 긴 안내는 여러 조각일 수 있습니다.

상세 고지: [VOICE-NOTICE.txt](VOICE-NOTICE.txt). 음성 유사도·발음의 청취 평가는 아직 하지 않았습니다.

## 저장·업데이트

개인 기록은 브라우저 localStorage에 저장하며 다른 기기로 자동 동기화되지 않습니다. 음성 캐시는 공개 음성 파일만 IndexedDB에 저장합니다. 브라우저 데이터를 지우기 전에 개인 기록을 백업하세요.

서비스워커는 앱 기본 화면·기본 자료·인사 파일을 저장합니다. YouTube 영상·음악, 새 사진과 자료 확인에는 인터넷이 필요합니다. 영상·음악 파일이나 가사 전문을 앱에 넣지 않습니다.

GitHub Actions의 공식 자료 점검은 매일 09:00 KST로 설정되어 있습니다. 공개 YouTube RSS와 소속사 공개 사진 자료를 확인하며 회원 전용 공지는 수집하지 않습니다. 공식 자료 검증 시각과 앱 동기화 시각을 구분하고 실패 시 마지막 정상 자료를 유지합니다. 일정의 빈 목록이나 회원 전용 페이지는 ‘행사가 없다’는 뜻이 아닙니다. GitHub 일정 실행은 지연되거나 장기 미사용 시 중지될 수 있습니다.

음성 파일은 무료 표준 CPU 작업으로 사전 생성합니다. 작업당 최대 2시간의 생성 예산을 두고 검증한 결과를 재사용합니다. 유료 API·GPU·비밀키는 사용하지 않습니다. 음성 생성 작업에는 정기 일정이 없습니다. metadata와 voice-index/voice-clips는 같은 주소의 프록시를 통해 갱신되어 자료 추가만으로 Netlify 앱 전체를 재배포하지 않습니다.

앱을 닫은 동안의 정시 음성 인사, 백그라운드 걸음 측정, 새 일정 푸시 알림은 제공하지 않습니다. 무료 호스팅 한도를 넘으면 배포·접속이 일시 중단될 수 있으며 유료 자동 충전은 사용하지 않습니다.

## 권리와 검증 범위

음악·가사·영상 파일과 모델 실행 파일은 배포물에 포함하지 않습니다. 공식 플레이어·링크를 이용하며 사진과 앨범 이미지의 권리는 원권리자에게 있습니다. AI 음성은 실제 임영웅의 녹음·발언·추천이 아닙니다. 모델 사용 가능 여부가 실제 인물의 목소리·이름·초상 이용 허가를 뜻하지는 않습니다.

소스·음성 파일·앱 주소는 공개되어 있습니다. noindex는 접근 통제가 아닙니다. 개인 기록을 저장소나 배포 파일에 넣지 마세요.

검증 기록은 TESTS.md를 참고하세요. 브라우저 기술 검사와 실제 휴대폰 청취·설치·비행기 모드 검사는 구분합니다.
